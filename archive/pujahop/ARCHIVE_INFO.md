## 📦 What is Preserved in this Archive

1. **Frontend Components (`archive/pujahop/src/components/`)**:
   - `pandals/`: Pandal directory, detail modal, crowd indicators, reviews
   - `metro/`: Kolkata Metro schedule, route calculator, live status
   - `passport/`: Digital Puja Passport & verifiable digital stamps
   - `route/`: Turn-by-turn routing & walking engine interface
   - `food/`: Historic Kolkata culinary trail (Aminia, Nizam's, etc.)
   - `campaign/`: Festival posters, banners, and Bengali visual art
   - `audio/`: Procedural dhaak player & heritage soundscapes
   - `copilot/`: AI Puja Copilot drawer interface
   - `layout/`: Header, footer, sidebar, mobile bottom navigation
   - `home/`: Cinematic hero sections and discovery views

2. **Context & State Management (`archive/pujahop/src/context/`)**:
   - `PujaHopContext.tsx`: Full application state, filters, active tabs, bookmarks, and itinerary state
   - `ThemeContext.tsx`: Dark/Light theme switching logic

3. **Application Routing & App Shell (`archive/pujahop/src/app/`)**:
   - `page.tsx`: Tab-based router
   - `layout.tsx`: Root HTML layout, SEO meta tags, font setup
   - `manifest.ts`: PWA Web App manifest

4. **Brand Assets & Documentation (`archive/pujahop/src/lib/brand/`, `archive/pujahop/README.md`)**:
   - Editorial typography configurations and cultural copy
