# AI Video Editor — Exports

## Purpose
This directory stores production-ready exported MP4 video renders generated by Remotion, HyperFrames, and FFmpeg pipelines.

## Output Structure
- `final-renders/`: Clean master MP4s ready for social distribution or ad deployment.
- `thumbnails/`: Automated high-CTR frame grabs with contrast and saturation enhancement.
- `render-reports/`: JSON manifests detailing frame render speed, encoder settings, LUFS audio statistics, and file size metrics.
