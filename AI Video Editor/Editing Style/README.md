# AI Video Editor — Editing Style

## Purpose
This directory defines the algorithmic rules, pacing formulas, sound effect placements, and transition behaviors that govern how the automated video editor cuts footage.

## Style Rules Summary
- **Pacing**: Fast-paced short-form engagement with a hook in the first 1.8 seconds.
- **Cut Frequency**: Cuts every 1.5 to 2.8 seconds to maintain visual dopamine and retention.
- **Camera Movement**: Subtle 1.05x-1.12x digital pushes (punch-in) on key punchlines; slow whip-pans on section transitions.
- **Audio Mix**: Dialogue normalized to -14 LUFS; background music side-chained (ducked) by -18 dB during speech.
- **Sound Effects (SFX)**: Swooshes on text fly-ins, subtle digital clicks on list popups, cinematic braam on beat drops.
